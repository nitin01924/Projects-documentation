# Projects-documentation

A curated list of projects, guides, and demos maintained in this repository.

## Projects

- **SyncSound RC1**
  - Location: [PROJECTS/SyncSound/README.md](PROJECTS/SyncSound/README.md)
  - Summary: A native Android release-candidate that streams music from a Host to approved Android clients on the same Wi‑Fi network or mobile hotspot. Audio is decoded to PCM by the Host, transported over UDP, and synchronized using a monotonic presentation timestamp. See the project README for setup, test plan and architecture details.

- **Note App (Full Stack MERN)**
  - Location: [note-webapp.md](note-webapp.md)
  - Summary: A modern notes application built with React (Vite), Node.js/Express, and MongoDB. Features include user authentication with email verification, notes CRUD, dark mode, and deployment instructions. See the project document for demo link, tech stack, and setup steps.
